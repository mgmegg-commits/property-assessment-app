# Follow-up prototype

`follow-up-prototype.dc.html` is the clickable prototype of the simplified build's follow-up screens, made on a Claude design canvas (Nov 26, 2026). The left side is the Follow-up page for the signed-in user. The right side is the phone page a facility contact opens from a personal update link.

It's a design reference, not app code: it runs only inside the canvas, the property, people and items are made up, and its markup uses the canvas's component format (`<x-dc>`, `<sc-for>`, `<sc-if>`, `{{ }}` holes). Match its layout, wording, colors (v1's) and flow; build the real screens in the app's own way.
